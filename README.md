# 🎮 Hangman Word Guessing Game (Python)

## 📌 About the Project
Hangman is a fun, terminal-based word-guessing game developed using Python. The computer randomly selects a word, and the player must guess the word one letter at a time before running out of lives.

This project is part of my **100 Days of Code: The Complete Python Pro Bootcamp — Day 7** learning journey.

## ✨ Features
- 🎲 Random word selection
- 🔤 Letter-by-letter guessing
- ❤️ Six lives to guess the word
- 🎨 ASCII art to display the Hangman stages
- ✅ Tracks correctly guessed letters
- ❌ Displays incorrect guesses and remaining lives
- 🏆 Win or lose messages

## 🛠️ Technologies Used
- Python 3
- `random` module
- Lists and loops
- Conditional statements
- String manipulation
- Modules and imports


## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## 🎯 How to Play

1. Run the game.
2. A random hidden word will be selected.
3. Enter one letter when prompted.
4. Guess the letters correctly to reveal the word.
5. Avoid incorrect guesses because you have only six lives.
6. Guess the complete word before your lives run out to win!
